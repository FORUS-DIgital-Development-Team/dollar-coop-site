# dollar.coop promotional site

Static public-facing site for the proposed dollar.coop cooperative network. This repository is a copy of the approved Sites version; its content and approved brand assets are served from `dist/`.

GitHub Actions deploys `dist/` to GitHub Pages on pushes to `main`. The staging domain is `dollar.forus.digital` until the `dollar.coop` domain is ready.

There is no build step. To preview locally, serve `dist/` with any static HTTP server.
